# Capability: gui

## Requirements

### Requirement: Главное окно
Система SHALL предоставлять визуальный интерфейс на Tkinter [ADR-4] [[ТЗ]]:
переключатель направления поиска «По имени | По телефону», поле ввода, кнопки
«Найти» и «Показать все», таблица результатов (колонки: ID, Имя, Телефон),
кнопки «Добавить», «Изменить», «Удалить». Кнопки «Изменить» и «Удалить» без
выделенной строки недоступны. Таблица до первого поиска пуста; после
«Добавить»/«Изменить»/«Удалить» видимые результаты перечитываются из БД.

### Requirement: Добавление и изменение записи
Формы добавления и изменения SHALL содержать поля «Имя» и «Телефон». Ошибки
API показываются пользователю человеческим текстом, без трейсбеков. Форма
изменения предзаполнена; сохранение применяет оба поля последовательно через
API; при ошибке второго шага форма остаётся открытой, показывается ошибка,
запись перечитывается из БД — частичное применение отображается честно.

#### Scenario: дубликат в форме добавления
- **WHEN** пользователь добавляет уже существующую пару
- **THEN** показано сообщение о дубликате; форма остаётся открытой; введённые
  значения не потеряны

### Requirement: Удаление с подтверждением
#### Scenario: случайное удаление предотвращено
- **WHEN** пользователь нажимает «Удалить»
- **THEN** запрашивается подтверждение (Да/Нет); при «Нет» запись остаётся

### Requirement: Пустой результат, пустой запрос и обзор
#### Scenario: ничего не найдено
- **WHEN** поиск не вернул записей
- **THEN** показано сообщение «Ничего не найдено»
#### Scenario: обзор книжки
- **WHEN** нажата «Показать все» или «Найти» с пустым полем (направление
  «По имени»)
- **THEN** показаны первые 500 записей по алфавиту; если записей больше,
  подсказка «Показаны первые 500 из N — уточните запрос» (CUJ-5)

### Requirement: Ошибки открытия БД
Ошибки старта (DatabaseLockedError, StorageCorruptedError) SHALL показываться
человеческим текстом в диалоге; приложение не падает с трейсбеком.

#### Scenario: второй экземпляр приложения
- **GIVEN** БД уже открыта другим экземпляром
- **WHEN** пользователь запускает приложение повторно
- **THEN** диалог с сообщением о занятой базе; данные не повреждены

### Requirement: Доступ к данным только через API
GUI SHALL обращаться к данным исключительно через `specs/api/` (правило
границ — `openspec/project.md`).

### Requirement: Отклик интерфейса
Бюджеты отклика GUI зафиксированы в `specs/performance/` (требование
«Бюджеты задержек», строка «Действия GUI») — здесь не дублируются.
