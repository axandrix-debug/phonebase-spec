# Design: data-model

- Канонизация выполняется один раз, на границе API (правило границ —
  `openspec/project.md`). Ядро и GUI работают только с каноническими
  значениями — одна точка истины [ADR-3].
- Имя хранится в двух видах: отображаемая форма (для GUI, исходный регистр) и
  `name_key` (для индексов поиска). Телефон хранится только в канонической
  форме — исходное написание не сохраняется [ADR-3].
- ID — монотонный счётчик; значение переживает рестарт и компактификацию:
  `next_id` хранится в снапшоте, при восстановлении берётся
  `max(снапшот.next_id, max id в хвосте журнала)` (см. `specs/storage/`).
- Таблица примеров канонизации в `spec.md` — одновременно база тестов:
  каждая строка таблицы становится параметром теста (практическое
  доказательство [[Урок]] стр. 45).
