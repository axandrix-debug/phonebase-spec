# Design: api

- Исключения вместо Result-типов: идиоматичный Python. Все ошибки — подклассы
  `PhonebaseError`, чтобы GUI мог поймать базовый класс и показать сообщение
  без разбора конкретных типов.
- Сетевой API отсутствует сознательно [ADR-5]; любое расширение в эту
  сторону — новый ADR, а не молчаливая предзаготовка в дизайне.
- API — единственная точка валидации: правила `specs/data-model/` применяются
  здесь, ядро доверяет входу. Это делает ядро простым, а правила — тестируемыми
  в одном месте.
