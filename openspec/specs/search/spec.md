# Capability: search

## Requirements

### Requirement: Телефоны по имени (префиксный поиск)
Система SHALL по запросу имени возвращать записи, чей `name_key` начинается
с ключа запроса (префиксное совпадение) [ADR-9]. Запрос канонизируется теми
же правилами, что и имя записи (`specs/data-model/`). Порядок выдачи — по
возрастанию name_key, затем id; объём выдачи ограничен параметром `limit`
(по умолчанию 500). Пустой запрос — валидный префикс «с начала базы»
(основа обзора книжки, CUJ-5).

#### Scenario: префикс находит полные имена
- **GIVEN** записи («Иван Петров», «+79211234567») и («Иван Смирнов», «+79015550000»)
- **WHEN** ищут «иван»
- **THEN** возвращены обе записи в порядке (name_key, id)

#### Scenario: начала имени достаточно
- **GIVEN** запись («Иван Петров», «+79211234567»)
- **WHEN** ищут «Иван П»
- **THEN** запись найдена

#### Scenario: лимит выдачи
- **GIVEN** 1 000 записей с name_key, начинающимся с «а»
- **WHEN** ищут «а» с лимитом по умолчанию
- **THEN** возвращены первые 500; способ увидеть остальные — уточнить префикс

#### Scenario: ничего не найдено
- **WHEN** ищут «Пётр Иванович»
- **THEN** возвращается пустой список; это не ошибка

### Requirement: Имена по телефону (точный поиск)
Система SHALL по запросу телефона возвращать все записи с совпадающим
каноническим телефоном — точное совпадение [ADR-9]. Порядок — по возрастанию
id; лимит не применяется.

#### Scenario: формат ввода не влияет на результат
- **GIVEN** запись («Иван Петров», «+79211234567»)
- **WHEN** ищут имена по телефону «8 (921) 123-45-67» или «9211234567»
- **THEN** найдена запись «Иван Петров»

#### Scenario: один телефон у нескольких имён
- **GIVEN** записи («Иван Петров», «+78122334455») и («Мария Петрова», «+78122334455»)
- **WHEN** ищут имена по телефону «+78122334455»
- **THEN** возвращены обе записи

#### Scenario: ничего не найдено
- **WHEN** ищут «+79990001122»
- **THEN** возвращается пустой список; это не ошибка

### Requirement: Канонизация поисковых запросов
Система SHALL применять к поисковому запросу те же правила канонизации, что и
к сохраняемым значениям (`specs/data-model/`), не применяя валидацию — иначе
«можно искать» из ТЗ [[ТЗ]] не выполняется для разных форматов ввода
[ADR-3, ADR-10].
