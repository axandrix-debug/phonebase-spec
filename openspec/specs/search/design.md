# Design: search

- Индекс имён: отсортированная по `(name_key, id)` структура в памяти
  (сортированный список с бинарным поиском или trie — выбор за
  имплементацией). Префиксный поиск = диапазон от первого вхождения
  префикса, первые `limit` записей — O(log n + limit); бюджеты
  `specs/performance/` не меняются [ADR-9].
- Индекс телефонов: хеш-таблица `канонический телефон → записи` — точный
  поиск O(1).
- Оба индекса строятся при открытии БД из восстановленного состояния
  (`specs/storage/`) и поддерживаются в памяти на каждой операции.
- Пустой префикс — начало отсортированного индекса: первые `limit` записей =
  обзор книжки (CUJ-5), без отдельного метода API.
