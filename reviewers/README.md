# Цикл ревью — Elephant + Goldfish (Практика 2)

«Слон» — основной агент с полным контекстом; у него неизбежен байес в пользу
собственных решений. «Золотые рыбки» — субагенты с пустым контекстом: видят
только артефакт и один вопрос, без мнения слона [[Урок]] стр. 41.

## Набор ревьюеров проекта

| Ревьюер | Файл | Изолированный вопрос | Модель |
|---|---|---|---|
| Спека-конформанс | `spec-conformance.md` | соответствует ли код спецификации | flash / low |
| ADR-конформанс | `adr-conformance.md` | не противоречит ли артефакт принятым ADR | flash / low |
| Эксперт по ошибкам | `error-handling.md` | прозрачность ошибок, отсутствие «глотания», логирование | flash / medium |
| Рыбка «лишнее» | `goldfish-spec.md` № 1 | что в спеке лишнее | flash / low |
| Рыбка «недостающее» | `goldfish-spec.md` № 2 | что недоспецифицировано или отсутствует | flash / low |
| Рыбка «спорное» | `goldfish-spec.md` № 3 | какие решения спорны | flash / low |
| Рыбка «перформанс» | `goldfish-spec.md` № 4 | реалистичны и проверяемы ли NFR | flash / medium |
| Критик | запускается на спорные находки | действительная проблема или мелочь/мнимация | дорогая / high, финальный проход |

## Правила цикла

1. Одна рыбка = один изолированный вопрос + только файлы артефакта. Никакого
   контекста слона в промпт не передавать.
2. Каждая находка обязана иметь два доказательства: **теоретическое**
   (рассуждение по тексту, цитаты) и **практическое** (конкретное проверяемое
   действие — тест, прогон) [[Урок]] стр. 45.
3. Слон агрегирует отчёты, приоритизирует; спорные находки передаёт критику.
4. Ложные находки отсеиваются вторым циклом (критиком), а не уменьшением числа
   ревьюеров.
5. Найден новый тип проблемы → в набор добавляется новый ревьюер (накопление
   от итерации к итерации).
6. ~80% ревьюеров — маленькие модели с низким/средним рённингом; дорогая модель
   с высоким рённингом — один раз, в конце, на стратегическую проверку
   результата целиком.
7. Токены — неотделимая цена качества; экономия на ревьюерах противоречит цели.
8. Рыбки для спеки и рыбки для кода — разные наборы; спека и код ревьюятся
   отдельно.
